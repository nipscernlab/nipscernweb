Simulação de Fluxo Contínuo de Sinais de Front-End em Instrumentação Nuclear Usando o Framework Lorenzetti

Nelson Cevidanes Nascimento de Assis, Guilherme Barroso Morett, Luciano Manhães de Andrade Filho, Tiago Aparecido Teixeira, Bernardo Sotto-Maior Peralva, Gustavo Barbosa Libotte

Congresso Brasileiro de Automática — CBA 2026

Open PDF Publications

Abstract

Simuladores de detectores de partículas, como o framework Lorenzetti, são essenciais para o estudo e projeto de novas arquiteturas de aquisição de dados para instrumentação nuclear. Geralmente, esses simuladores contemplam toda a cadeia de leitura, passando pela digitalização do pulso até o armazenamento de amostras. Embora bem estabelecida, essa filosofia de simulação apresenta limitações no estudo de algoritmos de trigger de primeiro nível (L1), nos quais os dados recebidos são contínuos. Atualmente, não é possível utilizar tais simuladores para analisar de forma direta esse processamento em tempo real. O presente trabalho faz uma reinterpretação dos dados de simulação de Minimum Bias, tratando-os como uma sequência contínua de colisões, e propõe um método para a geração de dados no regime free-running. Esta abordagem viabiliza o projeto e o desenvolvimento de sistemas de processamento de dados de calorimetria em tempo real, servindo como base para a validação de triggers de baixo nível no Lorenzetti.
